# Шаг 8. Больше валют, поиск и валюта отчета

На этом шаге работа с валютами стала удобнее и ближе к реальному использованию.

## Что улучшено

- добавлено больше популярных валют мира
- добавлены `PLN` и `BYN`
- поиск валюты появился прямо в форме создания счета
- добавлены быстрые кнопки популярных валют
- валюта отчета теперь выбирается прямо в mini app

## Что важно сделать вручную

Нужно выполнить новую SQL-миграцию:

- `supabase/migrations/002_add_more_currencies.sql`

Без этого в базе останется старый короткий список валют.

## Откуда берется курс

Сейчас курс валют берется не из Google.

Источник:

- `https://open.er-api.com`

Схема работы такая:

1. сервер запрашивает курсы у внешнего API
2. сохраняет их в таблицу `exchange_rates`
3. mini app и отчеты используют уже данные из нашей базы

## Почему это хорошо для MVP

Такой подход удобен, потому что:

- сервер не зависит от клиента
- курсы можно обновлять по расписанию
- приложение использует единый источник курсов для всех расчетов

## Что улучшилось в интерфейсе

### Для создания счета

Теперь пользователь может:

- искать валюту по коду
- искать валюту по названию
- быстро нажимать популярные валюты

### Для отчетов

Теперь можно выбрать валюту отчета прямо в интерфейсе.

Например:

- смотреть общий баланс в `USD`
- потом быстро переключиться на `EUR`
- или выбрать `PLN`
