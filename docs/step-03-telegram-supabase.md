# Шаг 3. Первая интеграция Telegram + Supabase

На этом шаге мы подключили базовые инструменты, чтобы проект стал "живым".

Теперь приложение уже умеет:

1. читать переменные окружения из `.env`
2. подключаться к Supabase
3. запускать Telegram-бота
4. обрабатывать команду `/start`
5. создавать или обновлять пользователя в таблице `app_users`

## Какие файлы добавлены

- `.env.example`
- `src/config/env.ts`
- `src/lib/supabase.ts`
- `src/services/users.ts`
- `src/bot/index.ts`

## Как это работает простыми словами

### 1. `.env`

В этом файле потом будут храниться секретные значения:

- токен Telegram-бота
- адрес Supabase
- service role key Supabase

### 2. `src/config/env.ts`

Этот файл проверяет, что нужные переменные действительно существуют.

Если какой-то переменной нет, приложение сразу падает с понятной ошибкой.

Это удобно, потому что ошибка видна сразу, а не где-то позже.

### 3. `src/lib/supabase.ts`

Здесь создается клиент Supabase.

Через него приложение будет:

- сохранять пользователей
- создавать счета
- добавлять операции
- читать отчеты

### 4. `src/services/users.ts`

Это маленький сервис для работы с пользователями.

Сейчас он делает только одно:

- берет Telegram-пользователя
- сохраняет его в таблицу `app_users`
- если пользователь уже был, обновляет его данные

### 5. `src/bot/index.ts`

Здесь создается Telegram-бот с polling.

Пока бот умеет только одну команду:

- `/start`

Когда пользователь отправляет `/start`, бот:

1. получает данные пользователя из Telegram
2. сохраняет их в Supabase
3. отправляет ответное сообщение

## Что нужно сделать вручную

Перед запуском нужно:

1. создать файл `.env`
2. скопировать туда значения из `.env.example`
3. подставить свои реальные ключи
4. выполнить SQL из `supabase/migrations/001_init_mvp.sql` в Supabase

## Что будет следующим шагом

Следующий логичный шаг для MVP:

1. добавить создание счетов
2. добавить список счетов пользователя
3. сделать первые кнопки в боте

Это хороший следующий шаг, потому что без счетов нельзя нормально добавлять доходы и расходы.
