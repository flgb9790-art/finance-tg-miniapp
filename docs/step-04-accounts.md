# Шаг 4. Счета пользователя

На этом шаге бот начал работать не только с пользователем, но и со счетами.

## Что уже умеет бот

После `/start` у пользователя появляются простые кнопки:

- `Добавить счет`
- `Мои счета`

## Как сейчас создается счет

Сценарий очень простой:

1. пользователь нажимает `Добавить счет`
2. бот просит ввести название счета
3. бот предлагает выбрать тип счета
4. бот предлагает выбрать валюту
5. бот просит ввести стартовый баланс
6. бот сохраняет счет в Supabase

## Какие типы счета сейчас есть

- `Наличные`
- `Карта`
- `Крипта`
- `Накопления`
- `Другое`

## Что делает кнопка `Мои счета`

Бот получает все счета пользователя из таблицы `accounts` и показывает их списком.

Пример:

1. TBC card | Карта | 1200.00 USD
2. Cash GEL | Наличные | 300.00 GEL

## Какие файлы добавлены или обновлены

- `src/services/accounts.ts`
- `src/bot/index.ts`

## Важное ограничение текущего MVP

Сейчас шаги создания счета хранятся во временной памяти Node.js.

Это значит:

- если сервер перезапустится, черновик создания счета пропадет
- для MVP это нормально

Позже, если понадобится, можно будет хранить такие шаги в базе данных.

## Как протестировать

1. запустить проект через `npm run dev`
2. открыть бота в Telegram
3. отправить `/start`
4. нажать `Добавить счет`
5. пройти шаги создания
6. нажать `Мои счета`

## Что будет следующим шагом

Следующий хороший шаг:

- категории
- доходы
- расходы

Но еще лучше сначала добавить:

- создание базовых категорий
- выбор категории из списка

Тогда операции уже можно будет вводить намного удобнее.
