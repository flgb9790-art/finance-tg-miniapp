# Шаг 7. Переводы, курсы валют и отчеты

На этом шаге mini app становится ближе к полноценному финансовому MVP.

Теперь приложение умеет:

- переводить деньги между счетами
- автоматически загружать курсы валют через API
- считать общий баланс в одной валюте
- строить отчет за неделю, месяц, 3 месяца или произвольный период

## Что добавлено

### 1. Курсы валют

Появился сервис курсов валют:

- `src/services/exchange-rates.ts`

Он умеет:

- загружать курсы через внешний API
- сохранять их в таблицу `exchange_rates`
- отдавать курс для конвертации

Также сервер теперь запускает фоновую синхронизацию курсов.

Дополнительно в интерфейсе есть кнопка ручного обновления курсов.

### 2. Переводы между счетами

Появился сервис:

- `src/services/transfers.ts`

И API:

- `POST /api/transfers`

Теперь пользователь может:

- выбрать счет-источник
- выбрать счет-получатель
- указать сумму списания
- при желании указать сумму зачисления
- если сумма зачисления не указана, приложение рассчитает ее по курсу

После перевода:

- баланс исходного счета уменьшается
- баланс целевого счета увеличивается
- операция попадает в таблицу `transfers`

### 3. Отчеты

Появился сервис:

- `src/services/reports.ts`

И API:

- `GET /api/reports`

Отчет теперь показывает:

- доходы
- расходы
- итог периода
- текущий общий баланс
- расходы по категориям
- количество переводов

## Какие экраны появились в mini app

Теперь в интерфейсе есть:

- блок общего баланса
- кнопка обновления курсов
- форма перевода между счетами
- список последних переводов
- форма отчета по периоду
- блок результата отчета

## Что важно понимать

### Автоконвертация

Сейчас конвертация делается по последним загруженным курсам из таблицы `exchange_rates`.

То есть это простой и понятный MVP-подход.

### Исторические курсы

Пока отчет использует не исторические курсы на дату операции, а текущие актуальные курсы.

Для MVP это допустимо.

Позже, если понадобится, можно сделать хранение исторических курсов по датам.

## Что стало лучше для пользователя

Теперь можно:

1. вести счета в разных валютах
2. переводить деньги между счетами
3. видеть общий баланс в одной валюте
4. строить отчет по периоду
5. смотреть расходы по категориям

Это уже очень близко к первой рабочей версии приложения.

## Следующий сильный шаг

Дальше логично сделать:

- более красивую навигацию mini app

Но даже сейчас приложение уже можно считать хорошим MVP-фундаментом.
