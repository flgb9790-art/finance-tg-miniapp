# Шаг 6. Дашборд, категории, доходы и расходы

На этом шаге mini app превращается в более полноценное приложение.

Теперь внутри Telegram уже есть не только список счетов, но и базовый рабочий интерфейс для ежедневного учета финансов.

## Что теперь умеет приложение

### 1. Дашборд

На главном экране теперь показываются:

- количество счетов
- количество категорий
- доходы за текущий месяц
- расходы за текущий месяц
- баланс по валютам

### 2. Категории

Пользователь теперь может:

- создавать категории доходов
- создавать категории расходов
- скрывать категории, которые больше не нужны

Скрытие сделано через архивирование.

Для MVP это удобнее и безопаснее, чем полное удаление.

### 3. Операции

Теперь можно добавить:

- доход
- расход

У операции сейчас есть:

- тип
- счет
- категория
- сумма
- дата и время
- комментарий

### 4. Баланс счета

Когда создается операция:

- доход увеличивает баланс счета
- расход уменьшает баланс счета

Это уже дает рабочую логику для MVP.

## Как это работает технически

### Категории

Добавлены новые серверные сервисы:

- `src/services/categories.ts`

И новые API-методы:

- `POST /api/categories`
- `DELETE /api/categories/:categoryId`

### Операции

Добавлены:

- `src/services/entries.ts`
- `POST /api/entries`

### Дашборд

Bootstrap mini app теперь возвращает:

- пользователя
- счета
- категории
- последние операции
- summary для главного экрана

## Важное ограничение текущего MVP

Сейчас операция записывается в валюте выбранного счета.

То есть на этом шаге мы не делаем:

- ввод операции в одной валюте на счет другой валюты
- автоматическую конвертацию внутри операций

Это сознательное упрощение для MVP.

## Что уже стало удобнее

Теперь пользователь может:

1. открыть приложение
2. создать счет
3. создать категории
4. добавить доход или расход
5. сразу увидеть обновленный баланс и последние операции

Это уже похоже на настоящее приложение, а не на набор тестовых экранов.

## Что будет следующим шагом

Следующий хороший шаг:

- переводы между счетами
- отчет по категориям
- фильтр по периоду
- общий баланс с учетом курсов валют

Именно после этого приложение станет полноценным MVP для личных финансов.
