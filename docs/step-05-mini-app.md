# Шаг 5. Полноценный интерфейс через Telegram Mini App

На этом шаге проект перестает быть только чат-ботом.

Теперь у него есть отдельный интерфейс внутри Telegram.

## Что добавлено

- HTTP-сервер на `Express`
- страница mini app
- API для загрузки пользователя и счетов
- API для создания счета из интерфейса
- кнопка `Открыть приложение` в Telegram-боте

## Как теперь устроено приложение

### 1. Telegram-бот

Бот все еще нужен, но теперь его основная роль другая:

- зарегистрировать пользователя
- показать кнопку открытия mini app

### 2. Mini app

Mini app открывается как обычный экран внутри Telegram.

На первом экране уже есть:

- профиль пользователя
- список счетов
- форма создания нового счета

### 3. Сервер

Node.js сервер теперь делает две вещи:

- запускает Telegram-бота
- отдает mini app и API

## Почему это лучше, чем работа через чат

Через чат неудобно:

- слишком много сообщений
- сложно видеть общую картину
- неудобно редактировать и просматривать данные

Через mini app уже можно сделать нормальный UX:

- экран балансов
- списки
- формы
- быстрые кнопки

## Важный момент про безопасность

Mini app передает на сервер `initData` от Telegram.

Сервер проверяет подпись этих данных перед тем, как отдать счета или создать новый счет.

Это важно, потому что сервер не должен просто верить любому `userId` из браузера.

## Что нужно для запуска mini app

Чтобы кнопка `Открыть приложение` заработала, нужен:

- публичный `HTTPS` URL

Его нужно записать в `.env` как:

- `APP_URL=https://your-domain.com`

Для локальной разработки часто используют:

- `ngrok`
- `cloudflared`

## Что уже умеет интерфейс

Сейчас в mini app можно:

1. открыть приложение из Telegram
2. увидеть свои счета
3. создать новый счет через форму
4. обновить список счетов кнопкой `Обновить`
