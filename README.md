# Finance Telegram Mini App

MVP-проект для учета личных финансов через Telegram Bot + Telegram Mini App.

## Что уже сделано

- создана новая отдельная директория
- добавлен базовый проект на Node.js + TypeScript
- подготовлена минимальная структура для дальнейших шагов

## Самый первый шаг

Мы начали с самого простого:

1. создали новый пустой проект
2. подключили TypeScript
3. добавили стартовую точку входа `src/index.ts`

## Что будет следующим шагом

Следом лучше сделать основу данных:

- сущности проекта
- schema для Supabase
- SQL-таблицы для MVP

Это правильный порядок, потому что бот, мини-апп и отчеты будут опираться именно на структуру базы данных.

## Что уже сделано на втором шаге

Теперь в проекте уже есть:

- `supabase/migrations/001_init_mvp.sql`
- `src/shared/domain.ts`
- `docs/step-02-database.md`

То есть база для MVP уже спроектирована на уровне структуры данных.

## Что уже сделано на третьем шаге

Теперь в проекте уже есть базовая интеграция:

- Telegram Bot
- Supabase client
- `.env.example`
- команда `/start`

Команда `/start` пока делает самое важное для начала:

- получает Telegram-пользователя
- создает или обновляет запись в `app_users`

## Что уже сделано на четвертом шаге

Теперь бот умеет:

- создавать счета
- показывать список счетов
- использовать простые кнопки для первого сценария

## Что уже сделано на пятом шаге

Теперь проект умеет работать как настоящий Telegram Mini App:

- бот показывает кнопку открытия приложения
- Node.js сервер отдает mini app и API
- mini app показывает счета
- mini app умеет создавать счета через форму

## Что уже сделано на шестом шаге

Теперь mini app умеет:

- показывать дашборд
- создавать категории
- добавлять доходы и расходы
- обновлять баланс счетов
- показывать последние операции

## Что уже сделано на седьмом шаге

Теперь mini app умеет:

- переводить деньги между счетами
- обновлять курсы валют через API
- считать общий баланс с конвертацией
- строить отчеты по периоду

## Что уже сделано на восьмом шаге

Теперь mini app умеет:

- работать с расширенным списком валют
- искать валюту при создании счета
- быстро выбирать популярные валюты
- выбирать валюту отчета прямо в интерфейсе
